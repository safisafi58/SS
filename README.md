# Vin Prompt

**Vin Prompt** — د AI فرمپټونو کتابتون اپلیکیشن (Flutter).

## ځانګړتیاوې
- 🎯 سپلاش سکرین — د ف لوګو سره، مېجنتا-بنفش ګرېډینټ
- 🏠 هوم سکرین — د فرمپټونو کارتونه د عکسونو سره
- 📋 د فرمپټونو ټولګه: AI هنر، لیکنې، کوډنګ، بزنس

## ځنګلېدل
```bash
git clone https://github.com/safisafi58/SS.git
cd SS
flutter pub get
```

## ځغلول
```bash
flutter run
```
